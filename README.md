# KhetAudit — AI Farmer Activity Audit

A Hindi-first farmer activity verification and product-claim audit system.

## Project scope
- Dashboard for activity audits, product knowledge, sampling, call audits, assessments, reports, and settings
- CSV activity import workflow
- Supabase schema migration for organization-scoped audit workflows
- NestJS API scaffold and worker boundaries for voice calls and background jobs

## Status
Prototype/scaffold only. Live authentication, production database integration, persistent sampling/scoring, telephony, and production security validation are not yet complete. Do not use for real farmer calls until consent, calling compliance, and access controls are validated.
